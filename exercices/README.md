# Exercices complémentaires

Versions corrigées préparées avec assistance : css-debug, ui-kit-audit, js-fit. Il ne s'agit pas de preuves que l'élève a réalisé les hypothèses personnelles ou les manipulations dans son éditeur.

## Bonus techniques
- UI kit : taille petite, survol, état désactivé. Book a demo réutilise les classes existantes. La couleur de marque se règle en un seul endroit : --brand.
- JavaScript : copie du code WAGON25 et du lien de partage ; retour du libellé après deux secondes.
- CSS : diagnostic des cinq erreurs dans css-debug/CORRECTIONS.md.

## À pratiquer sur l'ordinateur de l'élève
1. Ouvrir css-debug, inspecter le titre, désactiver/réactiver sa couleur dans Styles et observer la différence. Ces essais ne modifient pas le fichier.
2. Dans js-fit, comprendre defer ou le script placé en fin de body, textContent au lieu de value, le sélecteur .promo-code et la fonction passée sans parenthèses.
3. Sublime Text : Preferences > Settings, reprendre les paramètres du cours (tab_size: 2, translate_tabs_to_spaces: true, ensure_newline_at_eof_on_save: true, trim_trailing_white_space_on_save: true).
4. Emmet : développer une abréviation HTML, puis vérifier le résultat. Exemple : ul>li*3.

Aucune manipulation locale ou réponse personnelle non observée n'est présentée comme accomplie.
